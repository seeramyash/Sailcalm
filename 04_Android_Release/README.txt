ANDROID RELEASE APK

Build the APK from 02_MobileApp/MobileApp using:
  flutter pub get
  flutter build apk --release

Copy build/app/outputs/flutter-apk/app-release.apk here as:
  SailmCalm-app-release.apk

For GitHub, attach the APK to a GitHub Release (recommended for this ~70 MB binary).
The README download link expects the release asset filename to remain exactly SailmCalm-app-release.apk.
